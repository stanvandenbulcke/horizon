# src/lib – kleine algemene hulpjes

**Hoort hier:** kleine functies die niets met Horizon zelf te maken hebben en overal
bruikbaar zijn, zoals willekeurig iets uit een lijst kiezen (`random.ts`) of een id maken.

**Test:** elk hulpje heeft een testbestand ernaast (`random.test.ts`).

**Hoort hier niet:** iets dat over schelpen, eilanden of routines gaat (→ `game/`).

**Mag gebruiken:** niets anders. `lib/` staat helemaal op zichzelf.
