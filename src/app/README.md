# src/app – de ruggengraat

**Hoort hier:** alles wat de app bij elkaar houdt: het hoofdcomponent `App.tsx`, de 3 tabs
onderaan, de schermwissels (routes) en dingen die één keer bij het opstarten gebeuren
(zoals de service worker aanzetten).

**Hoort hier niet:** de inhoud van een scherm (→ `features/`), spelregels (→ `game/`).

**Mag gebruiken:** alles.
