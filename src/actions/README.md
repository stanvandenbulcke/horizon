# src/actions – de handelingen

**Hoort hier:** wat er gebeurt als je iets doet. Eén bestand per handeling, bv.
`completeRoutine.ts`: de spelregels vragen hoeveel schelpen je krijgt, dat opslaan, en
teruggeven welk feestje er moet komen.

Zo blijven schermen dun: een knop roept gewoon `completeRoutine(...)` aan.

**Hoort hier niet:** de regels zelf (→ `game/`), tekenen (→ `features/` of `world/`).

**Mag gebruiken:** `game/`, `data/`, `content/`, `lib/`.
